# ChatGPT & Codex Skills

几个解决 ChatGPT / Codex 日常问题的 Agent Skills，可以装进 Claude Code、Codex 或别的支持 SKILL.md 的 AI 助手。

| Skill | 解决什么 |
|---|---|
| [chatgpt-card-declined](skills/chatgpt-card-declined/SKILL.md) | 开 Plus / Pro 付款失败、卡被拒、续费扣不了 |
| [chatgpt-plan-chooser](skills/chatgpt-plan-chooser/SKILL.md) | Plus、Pro 5x、Pro 20x 怎么选 |
| [codex-usage-check](skills/codex-usage-check/SKILL.md) | 查网页版和 Codex 剩余额度、Model not found |

## 安装

把 `skills/` 下想要的文件夹复制到：

- Claude Code：`~/.claude/skills/`
- Codex：`~/.codex/skills/`

内容整理自 OpenAI 帮助中心和 [GetPlus](https://www.getplus.ai/) 的教程。OpenAI 的价格和额度会调整，以账号里显示的为准。
